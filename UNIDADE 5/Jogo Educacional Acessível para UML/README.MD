🎮 U.C. Battle — Jogo Educacional Acessível para o Ensino de UML
📌 Sobre o Projeto

O U.C. Battle é um jogo educacional desenvolvido com o objetivo de auxiliar no ensino de UML (Unified Modeling Language), especialmente Diagramas de Casos de Uso, promovendo uma experiência de aprendizagem interativa, inclusiva e acessível.

O projeto busca incluir pessoas com deficiência visual por meio da implementação de recursos de acessibilidade em jogos sérios.

🎯 Objetivos
Promover a inclusão de pessoas com deficiência visual.
Ensinar UML por meio de uma experiência gamificada.
Avaliar a acessibilidade em jogos educacionais.
Aplicar diretrizes de acessibilidade baseadas na WCAG 2.1.
🧠 Fundamentação Teórica

O projeto utiliza três conceitos principais:

Jogos sérios: ferramentas que promovem engajamento e aprendizagem.
UML: linguagem visual utilizada para modelagem de sistemas.
Acessibilidade: aplicação de diretrizes e adaptações que permitem a participação de diferentes usuários.
⚙️ Metodologia

O desenvolvimento foi organizado nas seguintes etapas:

Revisão bibliográfica.
Definição dos requisitos de acessibilidade (21 diretrizes).
Desenvolvimento do protótipo.
Realização de testes de usabilidade e acessibilidade.
🎮 O Jogo: U.C. Battle

O U.C. Battle apresenta um herói que enfrenta vilões em batalhas baseadas em perguntas sobre UML.

Principais características
Sistema de batalhas por perguntas e respostas.
Níveis com dificuldade progressiva.
Sistema de pontos de vida.
Habilidade especial que oferece dicas.
Aprendizagem baseada em desafios.
♿ Diretrizes de Acessibilidade

Entre os recursos implementados estão:

Alternativas textuais.
Contraste mínimo adequado.
Controle de áudio.
Navegação e operação via teclado.
Tutorial sem penalização.
Ausência de limite de tempo.
📊 Resultados e Contribuições

O projeto busca demonstrar como jogos educacionais podem contribuir para o ensino de UML e para a inclusão de pessoas com deficiência visual.

Entre suas principais contribuições estão:

Promoção da aprendizagem inclusiva.
Aplicação prática de critérios de acessibilidade.
Incentivo ao desenvolvimento de jogos sérios acessíveis.
Apoio ao ensino de Diagramas de Casos de Uso.
📌 Conclusão

O projeto U.C. Battle demonstra como os jogos educacionais podem contribuir para o ensino de UML, promovendo uma aprendizagem mais interativa, inclusiva e acessível para pessoas com deficiência visual.

A proposta também reforça a importância de considerar a acessibilidade desde as primeiras etapas do desenvolvimento de jogos digitais.
